## Making a test or a rubric

**Answer key test.** Name the test, choose the subject and date, and the number of questions. For A to D questions, tap the right answer for question 1; the key moves to question 2 by itself. For questions you mark by hand, choose **Right / wrong**.

**Skills.** Give questions a skill tag such as *Fractions* or *Reading for meaning*. Type it once on the first question of a group: it is copied down to the untagged questions below. Skill tags are what the class and student views add up.

**Rubric.** Name each criterion (for example *Ideas*, *Organisation*), give it a skill tag, and choose 3, 4 or 5 levels. To write a descriptor for every level, use a template file (*Templates*, below).

**From an example.** Three examples come with the app: a primary maths answer key, a reading fluency rubric and a writing rubric. They are examples to show how it works, **not official curricula or tests**. Change them to fit your class.

**From a file.** An NGO or a colleague can send you a template file (`.json`). Choose **Open a template file**; if anything in it is wrong, the app says what and where.
