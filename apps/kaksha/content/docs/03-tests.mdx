## Making a test or a rubric

From a class, tap **New test** and choose what kind of test it is.

**Answer key.** Name the test, choose the subject and date, and set the number of questions. Then tap the right answer for each question. You can switch any question to right-or-wrong, for short answers you mark by hand.

**Skills.** Give questions a skill tag such as *Fractions* or *Reading for meaning*. Type it once on the first question of a group: it is copied down to the untagged questions after it. Skills are optional, but they are what the class and student views add up.

**Rubric.** Name each criterion (for example *Ideas*, *Organisation*), give it a skill tag, and choose 3, 4 or 5 levels. To write a descriptor for every level, use a template file ([Templates](/docs/templates)).

**From an example.** Three examples come with the app: a primary maths answer key, a reading fluency rubric and a writing rubric. They are examples to show how it works, **not official curricula or tests**. Change them to fit your class.

**From a file.** An NGO or a colleague can send you a template file (`.json`). Choose **Open a template file**; if anything in it is wrong, the app says what and where. From a class's **Reports**, **Test as a file** saves your latest test the same way, without any marks, to share with another teacher.
