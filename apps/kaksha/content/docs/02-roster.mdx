## Importing a roster

Open a class, then **Students → Edit list**. You can:

- **Choose a file**: a CSV file with a column for roll numbers and one for names. **Download a blank list** gives you a ready file to fill in.
- **Paste from a spreadsheet**: select the two columns in Google Sheets or Excel, copy, and paste into the box. Tab-separated text is understood.
- **Add one student**: type a name; the roll number fills itself in.

Headers can be in English or Hindi (`roll`, `name`, `क्रमांक`, `नाम`), in either order. Without a header, one column is read as names and two columns as roll number then name.

Before anything is saved you see what will be added, and every line that will not be, with its line number and the reason: no name, a roll number already used, or text too long to be a name. Two children with the same name are both kept, with a note.

A student who leaves stays in old results but no longer appears when you mark new tests (**Edit → Mark as left the class**).
