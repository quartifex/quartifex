## Integration notes

AVENUE is **platform-agnostic**. What exists today:

- a **design system**: tokens, components and the interaction, motion and safety rules on this page;
- a **reference implementation** for the web (this demo), with the shared state and the driver rules as plain code;
- this **documentation**.

How AVENUE runs in a particular vehicle (the operating system, the display hardware, the vehicle signals it reads, such as speed and gear, and how it is certified) is **scoped with each partner**. We make no claim to run on any specific automotive platform today.

What a pilot typically settles first: the vehicle signal that defines "moving", the co-pilot screen's visibility from the driver's seat, the voice stack, and the test plan for the driver mode.
