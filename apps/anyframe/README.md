# anyframe

Responsive proof. **Open-source demo.** Planned address: `anyframe.quartifex.com`.

One scene, every screen. The QUASAR reveal (a concept visual drawn in code) is staged live
for a phone, a tablet, a laptop, an ultrawide and any shape in between, with the safe frame
and the resolution decision drawn over each, this window's viewport read live, and the
contact sheet of the whole device matrix embedded on the page. It proves the hardest part of
our niche: scroll and 3D-style scenes that hold up on every breakpoint and resolution.

Built with `@quartifex/plumb`, `safeframe`, `resolve`, `reel` and `contactsheet` (and
`rushes` to encode the sequence, `heft` to hold the budget).

## Run

```sh
pnpm --filter @quartifex/site-anyframe dev      # http://localhost:3200
pnpm --filter @quartifex/site-anyframe build    # encodes the sequence, then builds
pnpm --filter @quartifex/site-anyframe start
```

The build draws the 96 frames in code (`scripts/quasar.mjs`) and encodes them with rushes
into `public/sequences/quasar/` (git-ignored, about 3.2 MB on disk, under 1 MB per tier).

## Checks

```sh
pnpm --filter @quartifex/site-anyframe e2e      # behaviour tests and the launch gate
PW_CHANNEL=chrome pnpm --filter @quartifex/site-anyframe sheet   # contactsheet, all 36 profiles
PW_CHANNEL=chrome pnpm --filter @quartifex/site-anyframe heft    # budget.json "anyframe" block
```

`sheet` and `heft` start the production build themselves (build first) and write to
`reports/anyframe/`: `contactsheet.json` and `contactsheet.html`, and `heft.json` and
`heft.md`, are committed. Screenshots and the PNG sheet are raster and stay local. The page
reads `contactsheet.json` at build time, so run `sheet`, then build again.

## Deploy

`vercel.json` installs from the repo root and builds with Turborepo. Set the Vercel project's
root directory to `apps/anyframe` and the domain to `anyframe.quartifex.com`. Optional:
`QX_FONT_ORIGIN` for the brand fonts (see `licence-check.md`, Fonts).

## Provenance

- QUASAR reveal: concept visual, drawn in code (procedural SVG frames encoded by rushes). Not
  an astronomical image.
- Icon: from the Quartifex icon set (`assets/icons/svg/S13-anyframe.svg`).
- No photographs, video, models, datasets or sound.

## Launch gate

Do not deploy until every line is true.

- [x] The label is on the page and accurate: Open-source demo. Nothing invented is presented as
      real.
- [x] Rendered or generated visuals are captioned "Concept visual".
- [x] No raster, video or client-owned model is committed: the sequence is generated at build.
- [x] `prefers-reduced-motion` has a complete, usable path: the hero shows its final frame,
      Play is off, every screen follows the slider. Nothing is conveyed by motion alone.
- [x] Keyboard: a skip link past the scene, native controls throughout.
- [x] LCP under 2.5 s and CLS under 0.1 on a mid-range mobile profile (Playwright, Pixel 7,
      4x CPU, Lighthouse mobile network): see `e2e/launch-gate.spec.ts`.
- [x] Page weight within the `anyframe` budget in `budget.json`, checked by heft.
- [x] contactsheet run across the device matrix, report in `reports/anyframe/`.
- [x] Playwright behaviour tests pass against the production build.
- [x] `pnpm check` is green. Catalog entry marked `built`. `STATUS.md` updated.
