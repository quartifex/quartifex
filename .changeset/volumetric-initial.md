First release of `@quartifex/volumetric`: volumetric light shafts through a translucent medium in two variants under one settings API (density, scatter, colour temperature, source, dust, drift). A WebGL post-process for three.js (`/three`) and React Three Fiber (`/r3f`), and a Canvas 2D overlay for image sequences and static heroes (`/overlay`, `/react`). Quality scales with the GPU tier and understudy's live quality; the light holds still under reduced motion.
