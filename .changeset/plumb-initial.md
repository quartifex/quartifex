First release of `@quartifex/plumb`: a stable viewport layer. Steady `--plumb-*` CSS variables (small, large and dynamic heights, keyboard, pixel ratio), toolbar and keyboard movement kept apart from real resizes, one debounced layout event, fold posture, a React hook (`/react`) and ScrollTrigger wiring (`/gsap`).
